# fieldslug

Field timestamps and slug durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/fieldslug/

## Install / run

```bash
git clone https://github.com/theworker02/fieldslug.git
cd fieldslug
node src/cli.js
node --test
```
